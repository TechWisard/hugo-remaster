# Кузя: Алмазная лихорадка — восстановление на Godot

Перенос Windows-версии **Hugo: Black Diamond Fever** на **Godot 4.7.2**.
Версия проекта — **0.2.0-dev**. Импортер восстанавливает все восемь игровых
глав, исходные объекты, анимации, камеры, события, звук и видеоролики.
Главное меню запускает кампанию от вступления до финального ролика и титров.

Графика использует оригинальные модели и текстуры. Новые HD-модели и
HD-текстуры в эту версию не входят. Контакты и часть рендера обслуживает
Godot: совпадение с оригинальным EXE не объявляется побитовым или полным.

## Кампания

| Глава | Группа источника | Алмазов по исходному счётчику | Контрольных точек |
|---|---:|---:|---:|
| Пляж | 6 | 74 | 3 |
| Старая тропа Кику | 17 | 76 | 4 |
| Алмазные шахты | 27 | 85 | 5 |
| Транспортная линия | 36 | 74 | 4 |
| Нефтепровод | 46 | 93 | 4 |
| Алмазная фабрика | 55 | 51 | 1 |
| Авария | 59 | 86 | 4 |
| Побег | 69 | 99 | 0 |

В шахтах сумма значений предметов — 86, исходный счётчик — 85.
Импортер сохраняет оба значения, HUD использует исходное 85.

## Восстановлено

- 2 514 объектов в восьми главах: размещение, вложенные графы, все действия,
  движущиеся платформы и декорации.
- 14 действий Кузи и 27 отдельных анимаций гибели на особых поверхностях;
  исходные деформации вершин, трансформации и временные шкалы.
- Параметры движения, прыжка и ползания, физические размеры тела. Удары,
  подбор и контактные события используют исходные зоны столкновений.
- Таблицы состояний: переходы, здоровье, таймеры, сообщения, скрытые бонусы,
  контрольные точки и выходы из глав.
- Исходная collision-геометрия, свойства поверхностей и движущиеся тела.
- Пути камеры, CSnapTracker, исходная перспектива и событие встряски.
- Загрузка двух соседних участков, плоскости переключения по камере и
  исходные диапазоны включения объектов; состав участков сохраняется.
- Частицы: текстурные кадры, цвета, размеры, направления, время жизни и пулы.
- Четыре исходных режима mesh-материалов; 285 последовательностей текстур,
  190 анимаций цветов и 8 анимаций UV с исходными фазами и округлением.
- 355 WAV-ресурсов, последовательности звуков и 113 источников окружения.
- Семь сюжетных роликов, исходная видеозаставка ITE, восемь музыкальных
  дорожек и титры при их подключении.
- Пауза, выбор глав, звук, сложность новой игры, сохранения и резервная копия.

В Git находятся код, проверки и документация. Оригинальные ресурсы,
установочные EXE, сборки с ними и производные скриншоты в Git не входят.
Импортер читает локальные файлы и не запускает EXE игры.

## Запуск

Нужен [Godot 4.7.2 Standard](https://godotengine.org/download/archive/4.7.2-stable/),
без .NET. Откройте `game/project.godot` и нажмите **F5**.

```sh
godot --editor --path game
godot --path game
```

Без оригинальных ресурсов меню предлагает отдельный авторский тестовый
маршрут из версии 0.1. Он не выдаётся за исходный пляж.

## Импорт

Нужны Python 3, зависимости и `HUGO4.CD` из Windows-версии. Проверенная
русская копия: **42 946 560 байт**, SHA-256:

```text
fac39256dfdeedc4b19e07c171048e8c4e72a4fbe37cb4a8b8791239972aaa58
```

```sh
python -m venv .venv
# Windows:
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python tools/import_original.py "D:\Games\Hugo\HUGO4.CD"
```

В Linux/macOS используйте `.venv/bin/python`. По умолчанию импортируется
вся кампания. `--previews-only` оставляет профиль проверки трёх моделей.

Для роликов установите **FFmpeg** и передайте каталог с `CUTSC*.BIK` и `ITEMEDIA.BIK`.
Дорожки `Track02.ogg` … `Track09.ogg` подключаются из отдельного каталога:

```sh
python tools/import_original.py "D:\Games\Hugo\HUGO4.CD" --media-dir "D:\Games\Hugo" --music-dir "D:\Games\HugoMusic"
godot --headless --editor --path game --import
godot --path game
```

Параметры медиа необязательны. Отсутствующие файлы не заменяются посторонними.
Конверсия сохраняет исходные размеры, частоту кадров и соотношение сторон.
Проверенные предыдущие конверсии используются повторно только при совпадении
хешей исходника и результата.

Результат находится в `game/assets/generated/`, промежуточные данные —
в `.work/`. Оба каталога исключены из Git. Неудачный импорт сохраняет
предыдущий комплект. Исходники держите вне этих управляемых каталогов.

## Управление

| Действие | Клавиатура / мышь | Геймпад |
|---|---|---|
| Движение | WASD / стрелки | Левый стик |
| Прыжок | Пробел | A |
| Удар | E / ЛКМ | X |
| Присесть / ползти | Ctrl | B |
| Свободная камера | ПКМ и мышь | Правый стик в режиме орбиты |
| Исходная камера / орбита | C | — |
| Приближение свободной камеры | Колесо мыши | — |
| Вернуться к контрольной точке | R | — |
| Пауза | Esc | Start |
| Полный экран | F11 | — |
| Пропустить ролик | Пробел / Esc | A / B |

В исходных главах цифровое направление уже даёт максимальную исходную
скорость; Shift её не увеличивает. В тестовом маршруте Shift сохраняет бег.
На обычной сложности стартуют четыре жизни всего; HUD показывает три запасные.
После гибели мир и алмазы откатываются к контрольной точке, жизнь расходуется,
здоровье восстанавливается. R возвращает к точке без расхода жизни.

## Проверки и кадры

```sh
python -m unittest discover -s tests -v
godot --headless --editor --path game --import
godot --headless --path game --fixed-fps 60 --script res://tests/smoke_test.gd
godot --headless --path game --script res://tests/save_state_test.gd
godot --headless --path game --fixed-fps 60 --script res://tests/native_vm_test.gd
godot --headless --path game --fixed-fps 60 --script res://tests/native_scopes_test.gd
godot --headless --path game --fixed-fps 60 --script res://tests/campaign_smoke.gd
godot --headless --path game --fixed-fps 60 --script res://tests/campaign_flow_test.gd
godot --headless --path game --fixed-fps 60 --script res://tests/native_route_test.gd
godot --headless --path game --fixed-fps 60 --script res://tests/native_life_test.gd
godot --headless --path game --fixed-fps 60 --script res://tests/native_platform_test.gd
godot --headless --path game --fixed-fps 60 --script res://tests/native_material_test.gd
```

Проверки кампании, маршрутов и жизней требуют импортированную кампанию. Они проверяют загрузку
и связность глав, события и сохранения; это не ручное прохождение всех маршрутов.
Переменная `HUGO_BDF_SOURCE`
включает полный Python-тест импорта локального оригинала во временный проект.
Для настоящего кадра нужен видеодрайвер:

```sh
godot --path game -- --level=g006 --capture=/absolute/path/beach.png
godot --path game -- --level=g027 --capture=/absolute/path/mines.png
godot --path game --script res://tests/media_smoke.gd -- --capture=/absolute/path/intro.png
```

Результаты: [status.md](docs/status.md), [validation.json](docs/validation.json).
Проверки выполняются локально; GitHub Actions не используется.

## Windows

Установите экспортные шаблоны Godot той же версии и импортируйте ресурсы:

```sh
godot --headless --path game --export-release "Windows Desktop" ../builds/Hugo_Remaster.exe
```

Профиль включает JSON-манифесты и титры. У сборки 0.2 проверены PE/PCK,
загрузка 581 ресурса и запуск восьми глав непосредственно из
встроенного PCK через Linux-версию того же Godot. Нативный запуск EXE
на Windows пока не выполнен.
