# Состояние разработки — 0.1.0-dev

Дата первого этапа: 8 ноября 2026 года.

## Реализовано

- Публичный проект Godot с отдельным импортом оригинальных ресурсов.
- Авторский тестовый берег с препятствиями, мостом, контрольной точкой,
  12 алмазами и выходом.
- Управление персонажем и камера, пауза и повторное прохождение.
- Нормализация импортированного визуала Кузи; учебные модели при отсутствии GLB.
- Строгий разбор MDIC и проверка размеров/границ геометрии.
- Экспорт Кузи и пальмы; отдельные morph samples тела.

## Проверка

Проект проверяется в Godot 4.7.2 Standard, Linux x86_64. Интеграционный тест
использует настоящий SceneTree, физику и события областей, проверяет
приземление, движение, прыжок, сбор предмета, повторный подбор, возрождение,
завершение и сброс прохождения. Финальный прогон: **64 из 64 проверок
пройдены**, код выхода 0, stderr пустой. Включены регрессии паузы,
подтверждения меню клавишей Space и повторного прохождения.

Проверка формата использует синтетические корректные и повреждённые входы;
отдельно выполнен полный импорт фактического русского HUGO4.CD:
**14 модульных проверок и 1 интеграционная пройдены**.

Выполнена графическая проверка в OpenGL Compatibility / Mesa llvmpipe.
Исправлена потеря использования цветов вершин у двух поверхностей
импортированного Кузи: загрузчик создаёт отдельные материалы и включает
цвета для всех 17 поверхностей. Исходные GLB при этом не изменяются.
Пальмы ставятся на землю по реальному bounding box; пересвет убран.

Windows x86_64 EXE экспортирован со встроенным PCK. Проверены PE32+ AMD64
и встроенный контейнер данных; нативный запуск Windows здесь не выполнялся.
Версия движка, SHA-256, результаты и границы проверки:
[validation.json](validation.json).

## Границы этапа

Маршрут создан для разработки и пока не воспроизводит геометрию первого
уровня оригинальной игры. Не восстановлены полный object graph, AI,
исходные тайминги и переходы анимаций, все виды камер и столкновений,
сохранения между запусками, оригинальные материалы и полный игровой цикл.

Проверка Linux не доказывает запуск на Windows. Экспорт Windows отдельно
обозначается как экспорт; проверка EXE на настоящей Windows потребуется
перед заявлением о готовой Windows-версии.

Оригинальные игровые EXE во время анализа и импорта не исполнялись.
