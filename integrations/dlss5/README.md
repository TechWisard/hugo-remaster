# DLSS 5 и автоматический запуск без NR

Этот дополнительный пакет подключает **DLSS 5 Neural Rendering** через
GITC-Uplift 1.8.0 и ReShade 6.8.0 к Windows-версии ремастера. Это внешний
рендерер с настоящими вызовами NR, а не встроенный плагин Godot или замена
DLSS Super Resolution. Основной запуск умеет обходиться без NR.

В репозитории находятся установщик, запускатель, проверка и фиксированный
список зависимостей. DLL и чужие шейдеры загружаются отдельно в локальный
пакет. **Сборка и проверка файлов не означают, что модель уже запустилась на
видеокарте.** Это проверяется отдельной сценой на компьютере игрока.

## Автоматический выбор

| Условие | Что запускается |
| --- | --- |
| NVIDIA RTX, работающий native OpenGL, целые файлы NR | Ограниченная проверочная сцена, затем NR только при подтверждённом возврате обработанного кадра |
| AMD, Intel, NVIDIA без RTX, программный рендерер | Чистая копия игры, без ReShade и NR |
| Модель не создаётся, не возвращает кадр или зависла во время проверки | Чистая копия игры |
| Native OpenGL не запускается | Проверка чистого ANGLE и запуск через него |
| Уже запущенная NR-версия завершилась с ошибкой | Чистый перезапуск; при ошибке native-драйвера — ANGLE |
| NR прекратил работу, но игра продолжает отвечать | Игра продолжает работать; запускатель не завершает её из-за отсутствия NR |

`clean/` содержит только копию Godot EXE и, при необходимости, PCK.
Запускатель выставляет эту папку рабочей. В ней нет `opengl32.dll`, аддонов
или библиотеки модели. В обычной игре сохраняются HD-ресурсы, когда они
включены в сборку, и сглаживание MSAA. Для запасного профиля используются
MSAA 2× и масштаб рендера 100%; профиль NR использует MSAA 4× и 100%.
Сохранённые пользовательские графические настройки профили не переписывают.

Требуются Windows x64 и устройство/драйвер, на котором Godot может
отрисовать сцену через OpenGL 3.3 либо GLES 3 через ANGLE. Поддержку
произвольной видеокарты ниже требований движка этот пакет не обещает.

## Подготовить пакет из исходников

В корне репозитория, с Python 3.10 или новее:

```sh
python integrations/dlss5/build_pack.py --output .work/dlss5_pack --cache .work/dlss5_cache
```

Сборщик проверяет размер и SHA-256 каждого архива и извлечённого файла,
архитектуру PE и необходимые экспорты API. ReShade Setup открывается как
ZIP; установочные EXE при сборке не запускаются. Существующий выходной
каталог не перезаписывается.

Нужна свежая Windows-сборка этого ремастера с `--graphics-probe`. Оригинальный
`HUGO4_PC.EXE` не подходит. Установщик принимает только x64 PE и Godot PCK:
встроенный в EXE либо отдельный файл с тем же основным именем.

## Установить и запустить на Windows

В папке подготовленного пакета:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Install-Hugo-DLSS5.ps1 -GameExe ..\Hugo_Remaster.exe -Destination ..\Hugo-Auto
```

Каталог назначения должен быть новым. Исходная сборка игры остаётся на
своём месте. Для отдельного PCK с другим именем есть параметр `-PckFile`.

Откройте **`Launch-Hugo.cmd`** в созданном каталоге. Запускатель сначала
проверит чистый рендерер. На подходящей NVIDIA RTX он дополнительно
запустит маленькую движущуюся сцену: 320 кадров, окно 1280×720, предел
ожидания 120 секунд. Принудительно останавливается только эта явно
ограниченная проверочная сцена. Обычная игровая сессия такого таймера не
имеет.

Размер 1280×720 относится только к пробе. Реальная игра сохраняет выбранные
окно, монитор и разрешение, включая FHD, QHD, 4K и широкие форматы.
Проба проверяет путь NR; она не подтверждает запас видеопамяти или FPS в
4K. При нехватке ресурсов GITC может пропустить NR и сохранить обычный кадр.

Включён настоящий режим GITC `VramCheck=0` (Careful), с автоматическим
резервом 512 MiB (`BudgetMarginMB=0`). Он проверяет бюджет DXGI до создания
нейросетевого прохода и во время игры. Если даже один проход не помещается,
NR пропускается; при росте потребления памяти NR приостанавливается.
Выходное разрешение при этом не уменьшается. Если сам запрос бюджета DXGI
не работает, эта защита не получает достоверной оценки свободной памяти.
Это не гарантия восстановления после любого зависания GPU или драйвера:
запускатель повторно запускает чистую игру после ненулевого завершения
процесса, но не останавливает живую игровую сессию по таймеру.

Успешная проверка NR сохраняется вместе с SHA-256 журнала. Повторно она
используется только при совпадении данных адаптера/драйвера, игры, модели,
аддона, ReShade и настроек. Ошибка NR аннулирует этот результат. Название
видеокарты само по себе не считается доказательством поддержки модели.
В ключ входит отдельное `driver_info`; если сведения о драйвере получить
не удалось, успешная NR-проба не кэшируется.

Для принудительного запуска без NR:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Launch-Hugo.ps1 -ForceClean
```

Графическая проба не загружает кампанию или ролики и не меняет сохранение.
В самой игре чистый и нейронный варианты используют обычное сохранение
ремастера. `.cmd` применяют политику выполнения PowerShell только к своему
процессу; установки RHI и глобальных настроек Windows для этого не требуется.

## Модель для RTX 4090 и других RTX

Зафиксирована **ShortFuse compat-fp16 310.9.16**, которую
[манифест RHI 2.9.2](https://github.com/RankFTW/RHI/blob/939b1d9066763797ded3bedf30bea5175b6dcc3a/dlss_manifest.json)
обозначает как вариант для RTX 20/30/40/50. Автор GITC сообщил о проверке
этой совместимой сборки на RTX 4090 в D3D12 и Vulkan;
[релиз GITC 1.3.2](https://github.com/ghostinthecamera/GITC-Uplift/releases/tag/v1.3.2)
не является проверкой именно этого ремастера в OpenGL.

| Файл | SHA-256 |
| --- | --- |
| `nvngx_dlssnr_310.9.16.zip` | `dbeb1f2790b5c621887db99b1a56ac8bd5cb35207e8c074cbb806710f7460cab` |
| `GITC-Uplift/nvngx_dlssnr.dll` | `cdfa6c1ec784867182164c7836f324f087b5c9f374d0c9fe46f54999feabf3ed` |

DLL имеет размер 276 162 560 байт и версию PE `310.9.16.0`. Официальный
файл из RTX Remix с тем же номером версии имеет другой размер и хеш;
он не подменяет совместимый вариант в этом пакете.

## Начальные настройки NR

Включены один проход, полное рабочее разрешение текущего кадра,
`On Present`, `Keep faces = Off`. `Lumenite_Kernel` выполняется перед
`Uplift`; используются вычисленные по изображению векторы движения.
Это приближённые данные, а не геометрические векторы движка.

Эффект `Uplift` обязательно включён: на OpenGL он передаёт GITC
разрешённую ReShade-копию кадра, благодаря чему возможен MSAA.
Ограничение Feeder «MSAA выключен» на этот путь не переносится.

Меню GITC открывается клавишей **Home**. Там можно сравнить NR On/Off и
изменить рабочее разрешение, например на Custom 75%, если полного кадра
слишком много для видеокарты. NR сам требует вычислительных ресурсов;
этот пакет не добавляет Super Resolution или Frame Generation и не
обещает увеличение FPS. Порядок провайдера движения и `Uplift` сохраняйте.

## Проверка результата

`graphics-launch-status.json` показывает выбранный рендерер, результаты
проб и коды выхода. `dlss5-verification.json` относится именно к NR.
Для ручной повторной проверки есть `Verify-Hugo-DLSS5.cmd`.

Проверка NR требует в свежем журнале одновременно создания модели,
включённого evaluate и сообщения моста о возврате OpenGL-кадра. Одна
загрузка DLL, появление меню или файл с названием DLSS не засчитываются.
Старый журнал исключается при каждом запуске. Статус
`neural_frame_reported_by_backend` подтверждает сообщения backend;
качество картинки и производительность оцениваются отдельно.

На AMD/Intel обычен чистый запуск без такого статуса: успешность игры
смотрите по `graphics-launch-status.json`. Проверка только целостности
файлов доступна через `Verify-Hugo-DLSS5.ps1 -StaticOnly`.

## Удаление и лицензии

Закройте игру и выполните `Uninstall-Hugo-DLSS5.ps1`. Удаляются только
файлы, созданные установщиком. Изменённые чужие файлы и журналы сохраняются.
Исходная сборка не изменяется установкой или удалением этого пакета.

GITC использует MIT, ReShade — BSD-3-Clause; их уведомления находятся в
`licenses/`. Модель NVIDIA и её модификации остаются сторонними
компонентами. LumeniteFX распространяется по AGNYA: публичное повторное
размещение его файлов запрещено. Поэтому **публичный релиз репозитория
содержит исходники сборщика и lockfile, а не сформированный пакет DLL и
шейдеров**. Сборщик получает компоненты по закреплённым адресам их
распространителей для локальной установки.

Подробная проверка API и ограничения: [docs/dlss5_research.md](../../docs/dlss5_research.md).
